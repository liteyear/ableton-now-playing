ABLETON NOW PLAYING / LIVE STREAM SETUP • BY LITEYEAR DESIGN

Your music. On screen.

Set this up once. Before each stream, double-click Ableton Now Playing.

Connecting…
STEP 1 OF 4

Connect Ableton

Save your work and quit Ableton first. Then click below to install the included AbletonOSC connection.

If your User Library is in a custom location, select that folder instead. Its location is shown in Ableton → Settings → Library.

An existing AbletonOSC installation is kept unchanged.

Official AbletonOSC project and instructions ↗
STEP 2 OF 4

One setting in Ableton

  1. Open Ableton Live and your DJ Set.
  2. Open Settings / Preferences → Link, Tempo & MIDI (wording varies by Live version).
  3. In an unused Control Surface row, select AbletonOSC.
  4. Set that row’s Input and Output to None.

Wait for Ableton connected above. If AbletonOSC is missing, fully quit and reopen Live. This package uses Session View clip names.

STEP 3 OF 4

Choose your DJ decks

Select only the tracks holding your full songs. Leave drums, effects, and groups unchecked.

Waiting for Ableton…

Rename clips in Ableton to the text you want on screen. Muted decks are excluded. The title follows launches, not crossfader position, solo, cue routing, or loudness. Check deck selections after rearranging tracks or changing your Live Set.

STEP 4 OF 4

Your finished widget → OBS

All colors, fonts and layout are built in. One source. No CSS to enter.

  1. In OBS, select your stream scene. Click Sources → + → Browser, name it Ableton Now Playing, and click OK.
  2. Leave Local file unchecked. Replace the URL with:
  1. Set Width: 1100 and Height: 180.
  2. Enable Use custom frame rate and enter 1 FPS. Enable Shutdown source when not visible.
  3. Leave Custom CSS at its default. Click OK.
  4. Move the source above your video/camera sources in the Sources list, and make sure its eye icon is on.

If it is off-screen, select the source in OBS and choose Transform → Fit to Screen from its right-click menu. Then resize and position it.

The test card appears even without Ableton, then automatically returns to the live song. Normally the card hides when no selected song is playing and “Clear the title when stopped” is checked.

Ready: close this setup tab. Keep the app running. Hide or remove the old Text and Color sources; this Browser source is the complete widget.

After your stream

Open Ableton Now Playing again to return here, then click Stop widget. Your settings are saved for next time.
